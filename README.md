# 🤖 Infinity Chatbot

> An AI-powered research and conversational assistant built with Python and modern LLM tooling.

Infinity Chatbot is an experimental AI assistant focused on combining **LLMs, RAG, web search, document processing and conversational interfaces** into one practical application.

## ✨ What it explores

- 🧠 LLM-powered conversations
- 🔎 Web search and research workflows
- 📚 Document/PDF question answering
- 🧩 Retrieval-Augmented Generation (RAG)
- 🔤 Embeddings and vector search
- 🤗 Hugging Face models
- 🔗 LangChain-based AI workflows
- ⚡ Streamlit application interface
- 🚀 FastAPI-ready backend architecture

## 🛠️ Tech Stack

**Python · LangChain · Hugging Face · Transformers · Sentence Transformers · FAISS · ChromaDB · Streamlit · FastAPI · Scikit-learn**

The project targets Python 3.12+ and includes integrations for OpenAI, Google, Groq and Anthropic models.

## 🚀 Getting Started

This project uses **uv** for Python environment and dependency management.

```bash
uv sync
```

Then run the application entry point appropriate to the workflow you want to explore.
